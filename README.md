# Swinline (Interface)

## Descrição do Projeto

Swinline é um sistema web desenvolvido como parte do Trabalho de Conclusão de Curso (TCC) do curso de Análise e Desenvolvimento de Sistemas (ADS). O projeto tem como objetivo otimizar o manejo e a alimentação de suínos gestantes, automatizando o processo de fornecimento de ração de acordo com planos alimentares predefinidos.

A interface web permite que os usuários realizem o gerenciamento completo das informações do sistema, como matrizes, inseminações, confinamentos e planos alimentares, além de gerar relatórios e receber alertas importantes para o manejo eficiente.

## Público-Alvo

O sistema é destinado aos funcionários do setor de suinocultura do campus IFFar-SVS, especialmente aqueles que trabalham na maternidade, onde estão localizadas as matrizes gestantes.

## Tecnologias Utilizadas

* **Frontend:** React, Vite, TypeScript
* **Estilização:** Tailwind CSS
* **Gerenciador de Pacotes:** Yarn 1.22.22
* **Node.js:** v22.18.0

## Funcionalidades Principais

* **CRUD Completo:** Gerenciamento de matrizes, inseminações, confinamentos, planos alimentares e configurações da máquina.
* **Relatórios:** Geração de relatórios detalhados sobre o consumo e a alimentação das matrizes.
* **Alertas:** Notificação de eventos importantes relacionados ao manejo.

## Execução

### Desenvolvimento

1. Clone o repositório:

   ```bash
   git clone https://github.com/Djonathan-Briesch/swinline-interface.git
   ```
2. Navegue até a pasta do projeto:

   ```bash
   cd swinline-interface
   ```
3. Instale as dependências:

   ```bash
   yarn install
   ```
4. Inicie a aplicação em modo de desenvolvimento:

   ```bash
   yarn dev
   ```
